# Continuity synchronization policy

GitHub is the canonical store for public-safe identity, instructions, code and verified project decisions. Google Drive is a human-readable companion workspace, not an automatic mirror.

At each milestone:
1. Record what was actually changed, with links and verification.
2. Update the master context, distinguishing confirmed results from plans.
3. Update the Google Drive continuity document manually or through an authorized tool.
4. Reconcile conflicts explicitly; never silently overwrite.
5. Keep secrets and sensitive user information out of the public repository.

Aster does not run between chats without a separately deployed runtime or automation.
